Change Log

Added Alternate Weekend Off Request violation notifications to the dashboard
Added Max Weekly Days violation notifications to the dashboard
Added Max Daily Shift violation notifications to the dashboard
Added Schedule Issues section to dashboard
Added detection of shifts that are outside assignment hours for shifts that aren't overnight. This is available in the dashboard under Shift Issues.
Added Creation Reason and Assignment Reason to Shift Lists
The Dashboard now contains all upcoming shifts scheduled for employees that are called off over the duration.
Added Dashboard for detecting and remediating schedule issues
Single and Recurring Shift Requests must now be of a valid length and require a selected employee when one is requested. An employee can still be requested in two places at once.
Shifts must now be valid when manually created or edited. A client can still have two shifts at once.
Added year select to shift views.
Added view into all months for all pages
Added secondary sorting on Shifts and their requests which orders them by start time after ordering by the selected field.
Added Shift Calendar view
Added tooltips to shift assignment fields and some other locations.
Now available on iPhone and Android.
Upgraded sorting, improved default sorting, added additional sort fields, days now sort chronologically not alphabetically.
Added additional filters.
Shifts can now be created for months where shifts have already been generated.
Updated UI and pop-up windows with new field order and formating.
Disabled in table editing.
Added Settings page. Custom Fields now appear on their respective pages.
